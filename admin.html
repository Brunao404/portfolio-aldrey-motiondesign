Painel de projetos

Gerencie todos os projetos do portfólio — adicione, edite ou remova.

Depois de editar os projetos aqui, clique em Gerar projects.js e copie o conteúdo para o arquivo js/projects.js na pasta do site. As mudanças ficam salvas no navegador até você exportar.

Como adicionar um projeto novo

  1. Clique na aba + Novo projeto.
  2. Preencha o título, categoria, ano, descrição e ferramentas.
  3. Cole o ID do Google Drive do vídeo no campo "ID do arquivo".
  4. Clique em Salvar projeto.
  5. Vá na aba Exportar JS, gere o arquivo e copie para js/projects.js.

Como obter o ID do Google Drive

  1. Abra o vídeo no Google Drive.
  2. Clique em Compartilhar → Qualquer pessoa com o link.
  3. Copie o link. Formato: https://drive.google.com/file/d/ID_AQUI/view
  4. O ID é a parte entre /d/ e /view.

Como renomear um projeto

  1. Na lista de projetos, clique em Editar no projeto desejado.
  2. Altere o título no campo "Título".
  3. Clique em Salvar.
  4. Exporte o projects.js atualizado.

Senha do admin

  • Para trocar a senha, abra admin.html, localize SENHA_HASH e substitua pelo hash SHA-256 da nova senha.
  • Gere o hash em: emn178.github.io/online-tools/sha256.html
